# Instructions for coding agents

- Read `README.md` and `docs/PR_TEST.md` before making changes.
- Work only inside this repository.
- Do not modify unrelated files.
- Preserve the no-dependency Node.js setup unless the task requires otherwise.
- Add or update automated tests for every behavior change.
- Do not claim tests passed unless you ran them and observed the result.
- Do not commit, push, merge, or deploy unless the user explicitly authorizes it.
- Do not access production services or real user data.
- Report the files changed, commands executed, actual test results, and remaining risks.
