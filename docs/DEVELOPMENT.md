# Development

## Requirements

- Node.js 20 or newer
- npm

No third-party dependencies.

## Commands

- `npm start` — run server on http://127.0.0.1:3000
- `npm run dev` — run with `--watch`
- `npm test` — `node --test`
- `npm run check` — `node --check` on server.js, src/task-store.js, public/app.js

## Notes

- Work only inside this repository.
- Add or update automated tests for every behavior change.
- Do not commit, push, merge, or deploy unless explicitly authorized.
